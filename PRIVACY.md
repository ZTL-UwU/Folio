# Privacy policy

_Last updated: October 19, 2026_

Recto is a PDF viewer that works entirely on your device. It doesn't collect, send or share any information about you or the documents you open. It has no accounts, ads, analytics or telemetry, and it never connects to the internet by itself.

## What Recto stores on your device

To work, Recto opens the documents you choose and keeps a little information about them in its local data folder. When installed from the Microsoft Store, Windows removes this folder when you uninstall Recto.

- **Recent documents.** For each document you open: its file path, when you last opened it, the page you were on and your view settings (zoom, rotation, page layout). For documents that aren't password-protected, Recto also keeps the document's title and a small image of its first page for the start page.
- **Preferences.** Your settings, window size, and the printer and print options you last used.
- **Error log.** If Recto runs into an unexpected error, it writes the technical details to a log file. These can include the path of a file it was working with. The log stays on your device and isn't sent anywhere.

Recto also writes temporary files:

- **Attachments.** When you open a file attached to a PDF, Recto saves a copy in its temporary folder so it can be opened. A PDF attachment opens in a new Recto window, and its copy is deleted when you close that window. Copies of other attachments are deleted when you close the window you opened them from. If that fails, for example because another app still has the file open, Recto deletes it the next time it starts, once it's more than a day old.

## Your controls

- Remove a document from the start page with **Remove from list**, or remove all of them with **Clear list**. Its first-page image is deleted too.
- Turn off **Remember recent documents** in Settings to stop Recto from adding documents to the list.
- Uninstall Recto to remove everything it stored.

## When information leaves Recto

Only when you ask for it:

- **Links.** Clicking a web link in a document opens it in your web browser. Clicking an email link opens your email app with the address, and any subject or message text the link includes.
- **Attachments.** Opening an attachment that isn't a PDF hands it to the app Windows uses for that file type. PDF attachments stay in Recto.
- **Printing.** Printing sends the document to the printer you choose.
- **Copying.** Text you copy goes to the Windows clipboard.
- **Annotations.** Highlights and notes you add are signed with your Windows user name as their author, like in other PDF apps. When you save a copy of the document, the name is saved in it, and anyone you share the file with can see it.

What those apps and services do with the information is covered by their own privacy policies.

## File Explorer thumbnails

Recto includes a thumbnail handler that draws the first page of PDFs as their icons in File Explorer, which Windows uses while Recto is your default PDF app. It reads only the file being shown. Windows keeps these images in its own thumbnail cache, which you can clear with Disk Cleanup.
